# 🛡️ Asset Management System (Corporate Luxury Edition)

ระบบจัดการครุภัณฑ์ระดับองค์กรที่เน้นความพรีเมียม ใช้งานง่าย และประสิทธิภาพสูง พัฒนาด้วย Stack สมัยใหม่ที่องค์กรชั้นนำต้องการ

## ✨ ฟีเจอร์เด่น (Key Features)
*   **🏢 Dashboard & Data Analytics**: สรุปข้อมูลครุภัณฑ์ในรูปแบบกราฟที่สวยงาม เข้าใจง่าย
*   **🔍 Advanced Search & Filter**: ค้นหาข้อมูลแบบละเอียด แม่นยำ และรวดเร็ว
*   **🗂️ Category Management**: ระบบจัดการหมวดหมู่แบบ Drag & Drop พร้อมฟีเจอร์ Bulk Delete
*   **📧 Professional Authentication**: ระบบล็อกอินและกู้คืนรหัสผ่านผ่านอีเมล พร้อมดีไซน์ Corporate Blue
*   **🗺️ Map Integration**: แสดงตำแหน่งพิกัดครุภัณฑ์ผ่านระบบแผนที่อัจฉริยะ
*   **📱 QR Code System**: พิมพ์ QR Code สำหรับครุภัณฑ์แต่ละรายการเพื่อการตรวจสอบที่ง่ายขึ้น

## 🛠️ Tech Stack
*   **Frontend**: Next.js 14+, TypeScript, Tailwind CSS, Framer Motion
*   **Backend**: Prisma ORM, PostgreSQL (Adapter-pg)
*   **Authentication**: Better-Auth
*   **Email System**: SMTP Integration (Gmail)
*   **UI Framework**: Radix UI, Lucide Icons

## 🚀 วิธีติดตั้ง (Quick Start)
1. Clone โปรเจ็กต์นี้
2. ติดตั้ง Dependency: `npm install`
3. ตั้งค่าไฟล์ `.env` (ดูได้จาก `.env.example`)
4. รัน Database Migration: `npx prisma db push`
5. รันโปรเจ็กต์: `npm run dev`
